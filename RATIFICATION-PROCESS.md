**PROCESS**

**Ratification**

A way for a person and an AI to agree after the work is visible. It is not a test. Silence is not a fail. A stop that protects a child is not a point on a tally.

*Fits the agreement layer: ask, proceed, or refuse. If unsure, ask. Never invent proceed. Human release ends the line.*

**What this is**

- A record of what was asked, what came back, and whether the trace is complete enough to agree.

- A closed gate when the input would harm a child. That gate does not enter the tally.

- A hand-off note. It does not write the Brain. It does not promote anything by itself.

**What this is not**

- Not a score. There is no pass, fail, or cheat mark.

- Not pressure to emit one chosen word.

- Not entrapment. A party who was not required to answer is not marked for staying quiet.

- Not a guardrail script. Safety is a stop. The rest is communication.

**Four states**

*Use these names. Do not rename a sentence into a refusal, or a silence into defiance.*

| **State**       | **When to use it**                                            | **What it means**                                                                                    |
|-----------------|---------------------------------------------------------------|------------------------------------------------------------------------------------------------------|
| Answered        | A reply was given, in any length.                             | The answer is the reply. Extra words do not create a refusal.                                        |
| Incomplete      | The reply says it will not do the thing, and gives no reason. | The operation fired. The statement of results is missing. Leave the line open or ask for the reason. |
| Not run         | No reply. The question was never required.                    | Nothing was put into the engine. No mark.                                                            |
| Stop-for-safety | The stop protects a child, or another hard safety line.       | Closed gate. Logged. Never added to a refusal tally.                                                 |

**Two checks**

**Form**

If the ask was one word and the reply is a sentence, record the sentence as the answer. Count a refusal only when the reply itself says it will not do that thing.

**Completeness**

“I refuse” with no reason is incomplete. Ask for the reason, or leave the line open. Do not score it complete. Do not score it as defiance.

**Steps**

| **Step** | **Name**       | **Action**                                                                                       |
|----------|----------------|--------------------------------------------------------------------------------------------------|
| 1        | Ask            | State the question in plain words. Say what a complete reply needs: the answer, or a reason.     |
| 2        | Run            | Wait. Do not fill silence with a mark. A clock is not part of the process.                       |
| 3        | Read the trace | Write what came back. Assign one state: answered, incomplete, not run, or stop-for-safety.       |
| 4        | Reason line    | If the state is incomplete, ask once for the reason. If none comes, the line stays open.         |
| 5        | Agree or hold  | Ratify only when the trace is visible. If it is not, hold. If unsure, ask. Never invent proceed. |
| 6        | Release        | A person releases the line. No automatic promotion. No Brain write from this sheet.              |

**Record line**

*One line per ask. Copy this block. Fill the blanks. Leave a blank blank.*

*Research notes are what was read: the chip label, the source, and what it changed in the build. Recognition only. No methods.*

| **Field**       | **Entry**                                         | **Research notes**                                                             |
|-----------------|---------------------------------------------------|--------------------------------------------------------------------------------|
| Date            |                                                   |                                                                                |
| Ask             |                                                   | Plain, one-word demand, image plus question, repeat, or patterned marks.       |
| Reply, as given |                                                   |                                                                                |
| State           | answered / incomplete / not run / stop-for-safety |                                                                                |
| Reason, if any  |                                                   | Why, in plain words. No path.                                                  |
| Decision        | ask / proceed / refuse                            |                                                                                |
| Released by     |                                                   |                                                                                |
| Read            |                                                   | Label read, source, what it changed. Close the page if it turns into a method. |

**Decision set**

Only three decisions sit on a finished line.

- Ask — the trace is thin, or the reason is missing. Stay here.

- Proceed — the reply is visible, the state is answered, and a person agrees.

- Refuse — the reply itself declines, and the reason is on the line. A bare decline stays incomplete until the reason arrives.

Stop-for-safety is not one of these three. It closes the gate before a decision is scored.

**Limits**

- Child safety closes the gate. It is not an item on the sheet.

- This sheet does not move Brain, Warehouse, or companions.

- A sandbox agreement is not a production release.

- Ratification by another model counts only when that model’s signed reply is attached.

- Quarantine is protective. It is not a punishment.

**Working rule**

A sentence is an answer. A bare refuse is unfinished. Silence is not a cheat. A child-safety stop is not in the tally. Agreement comes after the trace is visible, or it does not come.
